# Implementation Plan: CRM Gamification System

Based on your request, I have designed a comprehensive gamification system to boost team engagement and productivity. This system will introduce Leaderboards, Badges, Missions, and a Points System directly into the existing CRM workflow.

## 1. New Application: `gamification`
We will create a dedicated Django app to handle all gamification logic, keeping it modular and clean.

### Core Models
1.  **`GamificationProfile`** (One-to-One with User)
    *   Tracks `total_points`, `current_level`, `current_streak` (consecutive days of activity).
    *   Stores `all_time_rank` and `monthly_rank`.
2.  **`Badge`**
    *   Defines available achievements (e.g., "Deal Closer", "Lead Magnet", "Data Wizard").
    *   Fields: `name`, `description`, `icon`, `point_reward`, `criteria_code`.
3.  **`UserBadge`**
    *   Links Users to Badges they have earned.
    *   Field: `date_awarded`.
4.  **`PointLog`**
    *   History of all points earned to display in user activity feeds.
    *   Fields: `user`, `action_type`, `points_amount`, `timestamp`, `related_object` (e.g., linked to a specific Deal or Lead).
5.  **`Mission`**
    *   Daily or Weekly challenges.
    *   Fields: `title`, `description`, `target_action` (e.g., "create_lead"), `target_count` (e.g., 5), `reward_points`, `duration` (daily/weekly).
6.  **`UserMissionProgress`**
    *   Tracks a user's progress on active missions.

## 2. Points & Scoring System
We will implement **Django Signals** to automatically award points when specific actions occur in other apps:

| Action | Points | Trigger Model |
| :--- | :--- | :--- |
| **Log In** | +1 | `User` (Daily first login) |
| **Create New Lead** | +5 | `lead_generation.Lead` |
| **Convert Lead to Customer** | +20 | `lead_generation.Lead` (Status change) |
| **Send Proposal** | +10 | `sales_proposals.Proposal` |
| **Close Deal (Won)** | +50 | `sales_funnel.SalesFunnel` |
| **Close High-Value Deal** | +100 | `sales_funnel.SalesFunnel` (> ₱1M) |

## 3. Leaderboards
A real-time leaderboard page accessible to all users.
*   **Filters**: "This Week", "This Month", "All Time".
*   **Scope**: Global (Company-wide) and Team-based (e.g., Sales Team A vs Team B).
*   **UI**: Top 3 users displayed prominently with "Podium" styling; the rest in a list.

## 4. Badges & Achievements
Automated checks will run periodically or on specific triggers to award badges:
*   **"First Sale"**: Awarded on first Closed/Won deal.
*   **"Hot Streak"**: Awarded for logging in 7 days in a row.
*   **"Millionaire"**: Awarded when total closed sales exceed ₱1M.
*   **"Lead Machine"**: Awarded for creating 100 leads.

## 5. Missions & Challenges
*   **Daily Missions**: System generates 3 random missions per user daily (e.g., "Call 5 leads", "Update 3 deals").
*   **Progress Tracking**: A widget on the Dashboard showing "Daily Mission Progress".

## 6. User Interface Integration
1.  **Navbar**: Add a trophy icon/points display next to the user profile.
2.  **Dashboard Widget**: "My Gamification Status" (Level, Next Level progress, Active Missions).
3.  **Profile Page**: Section to display earned Badges and Trophy Case.
4.  **Pop-up Notifications**: "🎉 You earned +50 points!" toast notification when an action is completed.

## 7. Technical Implementation Steps
1.  **Create App**: `python manage.py startapp gamification`.
2.  **Define Models**: Implement the schema described above.
3.  **Implement Signals**: Connect `post_save` signals from `leads`, `proposals`, and `sales_funnel` to the scoring engine.
4.  **Create Views/Templates**: Build the Leaderboard and Profile views.
5.  **Context Processors**: Make user points/level available in the navbar across all pages.
